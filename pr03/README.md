## 3. fork_demo.py

Программа создаёт дочерний процесс с помощью os.fork().
Ребёнок выводит свой PID и PPID и завершается.
Родитель вызывает os.wait(), получает статус завершения
и выводит код завершения ребёнка.

## 4. zombie.py

Зомби — это завершившийся процесс, запись о котором остаётся
в таблице процессов, пока родитель не заберёт его статус.
Для этого обычно используется wait() или waitpid().

Результат наблюдения через ps:

## Контрольные вопросы

1. Почему fork() возвращает два разных значения?

fork() возвращает 0 дочернему процессу, PID дочернего
процесса родительскому процессу и -1 при ошибке.

2. Что изменится, если вызвать exec без предварительного fork()?

exec заменяет текущий образ процесса новой программой.
Если exec успешен, исходный код процесса больше не выполняется.
PID процесса при этом сохраняется. Отдельный дочерний процесс
не создаётся.
